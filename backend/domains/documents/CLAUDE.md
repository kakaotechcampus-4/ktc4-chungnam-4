# ⑥ documents — 문서 관리 (알림장·관찰일지·공지)

만들어진 초안을 교사가 검토·수정·승인하고 학부모에게 노출합니다. 담당: 한상균. 공통 규칙은 [../../CLAUDE.md](../../CLAUDE.md).

## 파일 (목표 구조·구현 예정 포함)

| 파일 | 내용 |
| --- | --- |
| `models.py` | `DraftDocument`, `RevisionLog`, `UnclassifiedItem`, `Notice` |
| `schemas.py` | 검토·수정·승인 요청, 교사용/학부모용 응답 |
| `router.py` | `/documents` 엔드포인트 |
| `service.py` | 교사 검토·수정·승인·회수, 학부모 열람 |

## 규칙

- **H-1은 교사 검수와 학부모 공개를 구분합니다.** 미승인 초안은 검수 권한이 있는 교사에게 저장·조회·수정을 허용합니다. 학부모 공개와 외부 공유·복사·전송은 `status == approved` 및 대상 원아 접근 권한 검사 후에만 허용합니다. 초안 보관 기간은 별도 정책으로 확정합니다.
- 학부모 노출 경로는 **단일 게이트 함수 하나**로 모으고 승인·원아 매칭 권한을 함께 검사합니다. 학부모용 응답에서 게이트를 우회해 문서 본문을 담지 않습니다. 교사 검수용 응답은 교사 권한을 별도로 확인한 뒤 초안 본문을 제공할 수 있습니다.
- 교사용 응답과 학부모용 응답 스키마를 분리하세요. 같은 스키마를 재사용하면 미승인 본문이 새는 경로가 생깁니다.
- 상태 전이(초안 → 검토 → 승인 → 회수)는 `service.py`의 한 함수에서만 바꿉니다. `router.py`에서 status를 직접 대입하지 않습니다.
- 모든 수정은 `RevisionLog`에 남깁니다. 원문을 덮어쓰기만 하지 않습니다.
- 귀속 실패·재시도 상한 초과 건은 `UnclassifiedItem`으로 받아 교사가 처리합니다.
- 학부모 열람은 매번 `audit`에 `AccessLog`를 남깁니다 (NFR-05).

## 필수 테스트

- 검수 권한이 있는 교사는 미승인 초안을 저장·조회·수정할 수 있고, 권한이 없는 사용자는 접근할 수 없다 (H-1).
- 미승인 초안이 학부모 노출 API로 나가지 않는다 (H-1, FR-08)
- 모든 열람 API 호출이 `AccessLog`를 남긴다 (NFR-05)

## 다른 도메인과의 관계

- `agents`: 초안 생성 결과 수신
- `organization`: `Child`, 학부모–원아 관계로 열람 권한 판단
- `audit`: 열람 로그
